# Neural Network Activation Functions

This project contains three separate Streamlit applications developed to visualise neural network activation functions using Python.

### ReLU
Visualises how negative input values are converted to zero, while positive values remain unchanged.

### Sigmoid
Visualises how input values are transformed into outputs between 0 and 1, forming an S-shaped curve.

### Tanh
Visualises how input values are transformed into outputs between -1 and 1, forming an S-shaped curve.

The applications include interactive input sliders, mathematical formulas, graphical visualisations and output values.
